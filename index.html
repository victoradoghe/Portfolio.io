01 About Who you'd be working with

I care about the details most people scroll past.

I'm a self-taught software engineer. I build interfaces with React, TypeScript and modern CSS — the kind that load quickly, work with a keyboard, and don't fall apart on a mid-range phone.

The web is where I started, not where I stopped. I ship mobile apps with React Native and Expo, and desktop apps with Electron and Tauri — same instincts about performance and accessibility, different constraints to respect on each platform.

Most of what you'll see below started as a question I wanted answered: how fast can this get, how much of it can I make accessible by default, how little JavaScript can it ship. I write the documentation too, because a project nobody can pick up isn't finished.

Right now I'm taking on freelance work across web, mobile and desktop, and open to junior engineering roles.
